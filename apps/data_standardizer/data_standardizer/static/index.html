The same plant, three systems, three conventions

A building management system exports CSV in local time, °C and decimal commas. The SCADA API returns JSON with Unix milliseconds, °F, gallons per minute and tons of refrigeration. The test rig writes Excel in kelvin, litres per second and watts. Before anyone can compare them, someone spends a day on conversions and time zones, and the next month does it again.

  1. Read any mix of CSV, Excel, Parquet, JSON and HDF5. Separators, decimal commas and date formats are detected.
  2. Map: each column gets its physical quantity, unit, a canonical name and a target unit. Review and edit the draft.
  3. Unify into one table in UTC with consistent units, with a manifest that records every conversion.
  4. Check: where two sources measure the same thing, their agreement is reported. A wrong unit or time zone shows up immediately.
  5. Reuse the mapping as a recipe: the same JSON standardizes next month's files through the API.
